# Curoflow CV · UX Designer, Self-Service

Customized from CV-UX-Internship-Sweden for Curoflow's "UX Designer · Self-Service"
role (July 2026). Angle: the Agent X case study framed as onboarding work, plus
twelve years at Konduko as the customer of Swedish healthcare systems.

- `index.html`: online CV (EN/SV toggle)
- `print-source.html`: static A4 source for the PDF (English only)
- `make-pdf.command`: builds `CV_Ioannis_Koupidis.pdf` with Google Chrome
- `cover-letter.md`: application cover letter text
- `portrait.jpg`: shared portrait

Note: run `make-pdf.command` after any edit so the PDF matches the page.
Content edits to index.html go in BOTH the static HTML and the I18N dictionary
(en + sv), then get mirrored into print-source.html.
